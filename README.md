# Hytale HiveWorld Mod

> **⚠️ Warning: Early Access**    
> The game Hytale and this mod are both in early access! Features may be
> incomplete, unstable, or change frequently. Please be patient and understanding as development
> continues.

Explore a new Fragment of Orbis: The Scarak HiveWorld

The world is separated in 3 layes, the bottom nursery, the middle pathway and the upper royal gallery.
The higer you go, the harder it get, but Mithril await you at the top.

The mod is still a work in progress.

Current features:

- New Portal fragment craftable at the arcanist wotkbench for 10 chitin and 10 scarak eggsacks.
- A 30min endurance trial in a custom biome.
- Balanced Mithril ore spawn at the upper layer.
- No loot loss on death, but kicked out of the instance.
- High risk of death by falling, be warned !

Experimental features:

- A "Cull the Scaraks" questline system rewarding mithril ingot and more in the future.
- it can be started with the command "/objective start line HiveWorld_ObjectiveLine", right now the UI is obscurred by the portal close countdown, but the quest itself works.

Planned future features:

- Add and improve behaviour of Scarak Broodmother and Scarak Defender.
- Add custom decorative blocks exclusive to the dimension.
- Add one or two custom bosses (the Broodqueen and/or the Hivemind).
- Add more prefabs with potentially unique loots to make exploration more interesting.
- Improve Glowshroom and other lights placement to form more patterns to be more visually appealing.
